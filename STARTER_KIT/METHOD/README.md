# Method snapshot

This folder is reserved for copies of Human Truth Driven Design methodology.

Do not write product work here. Project truths, boards, discoveries, milestones, bootstrap, and lessons live in the sibling folders above this one. This project's `HUMAN_TRUTHS/` is not the canonical HTDD registry.

When the essays in the HTDD repository are ready, copy these trees from that repository's root into the matching children here:

```text
cp -R FOUNDATIONS/.   METHOD/FOUNDATIONS/
cp -R METHODOLOGY/.   METHOD/METHODOLOGY/
cp -R HUMAN_TRUTHS/.  METHOD/HUMAN_TRUTHS/
cp -R DISCOVERIES/.   METHOD/DISCOVERIES/
```

Do not copy `STARTER_KIT/`, `CASE_STUDIES/`, or the HTDD root README into this folder.

It is safe to refresh these four trees later the same way. They must not contain product writing.
