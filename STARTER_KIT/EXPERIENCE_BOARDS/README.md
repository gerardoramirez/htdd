# Experience Boards

This folder is the living canonical board set for this project.

Milestones must not own or replace these boards. A milestone may reference them, record reviewed status in `BOARD_SNAPSHOT.md`, or keep frozen copies in `board_snapshot/` only when historical traceability is required.

Experience Boards describe the emotional responsibility of each meaningful moment. They are not screen inventories.

Every board should answer:

- What human experience are we protecting?
- What should someone feel?
- What should the product intentionally refuse to do?
- What designed object replaces the ordinary product move?
- How should AI behave?
- What must engineering preserve?
- How do we know the experience succeeded?

Copy [TEMPLATE.md](TEMPLATE.md) for each board. Name files so the sequence of the experience is obvious.
