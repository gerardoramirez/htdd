## Governing stops (2026-11-01)

- A stale agent file stops implementation. A milestone is not governing until it restates what still binds.
- A quality pass cannot add a surface, collection, access path, invitation channel, or discovery query.
- A contract change updates the milestone status record. A red contract test means the ticket is not implemented.
- Product repositories that already copied the kit follow the migration note in that revision.
